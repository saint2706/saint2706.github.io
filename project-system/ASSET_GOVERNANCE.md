# Asset governance

For every external/generated asset record: ID, file path, type/purpose, source URL, creator/owner, license/version, permitted uses/restrictions, attribution, modification rights, retrieval date, hash where useful, optimized variants, alt text/caption/long description and approval state.

Prefer original/code-generated SVG, CSS and diagrams. Existing project images require quality/relevance review. External art/media require clear compatible rights. Unknown, scraped or watermarked assets are rejected. No user portrait/selfie/AI likeness. Optimize raster assets and provide responsive variants. Meaningful content cannot exist only in background images. Use descriptive alt text for informative images and empty alt for decorative imagery.
