## 3. Original-asset and licensing principles (proposed)

1. Default to assets made for this site (typography, diagrams, generative graphics, objects the owner creates). No portrait or likeness of the owner.
2. Any third-party artwork needs a recorded licence page, access date, creator, and the exact terms read; a museum or "public domain" label is not enough without that record. CC0 does not remove the need to check that the item itself is CC0.
3. Fonts: prefer open-licence families or system fonts; no paid fonts without approval.
4. Every asset gets an entry in the asset inventory (`project-system/audit/05-asset-provenance-inventory.csv`) with alt text.
5. Credits page and behind-the-scenes note (D01 lesson) published with the site.

## 4. Cross-reference lessons

- Make each space's mode explicit (D05, D04); keep the lab separate from professional content.
- Static text must carry the meaning of every interactive piece (D03); fits the audit finding that the SPA ships an empty shell.
- Visible dates and status build trust in a living site (D06, D04).
- Motion needs a global off switch and a reduced-motion path (S01-S03).
- Avoid commercial banners inside content lists (D04, D07).
