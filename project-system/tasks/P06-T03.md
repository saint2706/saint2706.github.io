# P06-T03 — Verify progressive enhancement and accessible equivalents

**Phase:** P06  
**Status:** planned  
**Authorization:** pending-user-phase-approval

## Objective

Ensure all important experiences have equivalent accessible routes.

## Repository context

Every significant interaction must retain essential content/functionality access.

## Scope

- No-JS/core-content behavior
- Keyboard/screen reader
- Reduced motion/touch alternatives
- Error/loading/offline states
- Canvas/WebGL alternatives

## Preconditions

- Interactive components complete

## Ready-to-copy prompt

> Inspect all advanced components. Test keyboard, screen readers, focus, motion, touch and failure. Ensure essential content/functionality is available equivalently. Document remaining limitations.

## Acceptance criteria

- [ ] No critical path depends on inaccessible motion/canvas
- [ ] Core content survives missing JS where feasible
- [ ] Accessible names/roles/states
- [ ] Critical blockers remediated
