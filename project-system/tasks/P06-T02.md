# P06-T02 — Build justified visualizations and explainers

**Phase:** P06  
**Status:** planned  
**Authorization:** pending-user-phase-approval  
**Dependencies:** P04-T01

## Objective

Add data-driven experiences only when they improve understanding.

## Repository context

Visualization optional/context-specific; no charts merely because user works in analytics.

## Scope

- Define user question and intended insight
- Verify data source/license/limitations
- Select chart and annotations
- Accessible table/text alternative
- Responsive performance

## Preconditions

- Specific approved use case and data rights

## Ready-to-copy prompt

> For each proposed visualization, state the question, provenance, limitations and intended insight. Choose simplest effective rendering method. Provide accessible equivalent and validate responsiveness.

## Acceptance criteria

- [ ] Every chart answers a documented question
- [ ] Data provenance/limits visible
- [ ] Accessible equivalent present
- [ ] Performance cost justified

## Validation commands

```bash
pnpm run lint
pnpm run test:run
pnpm run build
Playwright interaction/a11y tests
```

## Expected deliverables

- `Visualization components`
- `data provenance`
- `tests`

## Evidence required

- Source dataset, screenshots, accessibility evidence

## No scope creep

- No decorative charts
- No unsupported/private data
- No library adoption without comparison
