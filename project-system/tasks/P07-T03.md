**Status:** planned

## Objective

Verify release candidate security and privacy posture.

## Repository context

Security/privacy/factual integrity highest priority; no analytics/tracking; server-side credentials only.

## Scope

- Dependency/vulnerability audit
- Secret scan/build artifact inspection
- CSP/headers/Worker controls
- Input/sandbox security
- Actions permissions/pinning
- External data and privacy inventory

## Preconditions

- Release candidate and deploy config stable

## Ready-to-copy prompt

> Review dependencies, secrets, Actions, host security headers, Worker, forms, sandbox, input handling and third-party requests. Verify client build contains no API keys. Fix or block severe findings.

## Acceptance criteria

- [ ] No critical/high unmitigated release blocker
- [ ] No client secrets
- [ ] Least-privilege actions and pinned SHAs
- [ ] Privacy inventory clean
- [ ] Severe issues block release
