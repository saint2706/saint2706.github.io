## What this is

Personal portfolio at https://saint2706.github.io — React 19 + Vite 8 SPA, Tailwind v4, Framer Motion, React Router 7, Gemini chat, Pyodide playground.

- Entry: `src/main.jsx` → `HelmetProvider` → `ThemeProvider` → `src/App.jsx` (BrowserRouter, lazy routes).
- Routes: `/`, `/projects`, `/resume`, `/blog`, `/contact`, `/games`, `/playground`, `*`.
- Pages in `src/components/pages/`, cross-cutting UI in `shared/`, games in `games/`; `src/data/` holds resume, snippets and blog data.
- Tests are colocated `*.test.js(x)`; Vitest + jsdom + Testing Library, setup in `src/setupTests.js`. There is no tsconfig; a few utility files use `.ts`.
- Theme names in code are still `neubrutalism`, `neubrutalism-dark`, `liquid`, `liquid-dark` (`src/components/shared/theme-context.js`). "Editorial" is prose only, and the legacy term "aura" is forbidden in `src/` (CI check).

## Commands

```bash
pnpm install
pnpm dev                 # http://localhost:5173
pnpm test:run            # CI form; `pnpm test` is watch mode
pnpm exec vitest run src/utils/security.test.js   # one file
pnpm lint                # ESLint + lucide icon-export check
pnpm format:check        # `pnpm format` to fix
pnpm build               # prebuild regenerates llms.txt / sitemap.xml
pnpm test:security-full
```

- **pnpm-only** (`pnpm@12.15.0`, Node `^24.15.0 || >=26.0.0`). Never use `npm`/`npx`; never add `package-lock.json` — CI fails.
- `pnpm build` runs `prebuild` → `generate:geo`, writing gitignored `public/llms.txt` and `public/sitemap.xml`. Edit the generators, not the outputs.
- CI order: `format:check` → lockfile policy → no-aura → `lint` → tests (Ubuntu/Windows/macOS × Node 24/26) → `build` → security scripts. Run the matching local checks before a PR.
- Prettier is single quotes, semicolons, 100 columns, LF; `pnpm format` applies it.
- `src/data/blogs.json` is generated by `scripts/sync-blogs.js` (scheduled Action, every 3 days). Hand edits are overwritten.

## Security

- CSP is the `<meta>` tag in `index.html`; `public/_headers` is not honored by GitHub Pages. Add any new external origin to the CSP and keep `pnpm test:csp` passing.
- `react/no-danger` is an error. Sanitize user input with `src/utils/security.js`; keep the chat/history limits in `src/services/ai.js`.
- Pyodide is pinned to v0.24.1 with SRI in `src/components/shared/pyodideLoader.js`. `scripts/verify-sri.js` hard-codes the expected hash — a version bump requires updating both.
- Prefer `VITE_GEMINI_PROXY_URL`; `VITE_GEMINI_API_KEY` is local-only and must never ship. Only `.env.example` may be read or committed. `.env*` and `package-lock.json` are gitignored, and CI fails if `package-lock.json` is present; a Claude Code `Edit|Write` hook also blocks `.env*` and non-pnpm lockfiles. There is no git hook, so never force-add these files.
- Tailwind v4 is configured through `src/index.css` (`@import 'tailwindcss'; @config "../tailwind.config.js";`), not by auto-detection.

## Git and release

- Never commit or push to `main`; use one phase branch per phase, then a PR with a squash merge. `main` is protected by ruleset `protect-main`, and merging to `main` deploys production.
- Never force-push, rewrite history, `reset --hard`, `clean -f`, or delete branches. Preserve existing user work.
- GitHub Actions must stay pinned to full 40-character SHAs; `workflow-lint.yml` enforces this.
- For project tasks: record evidence, update Markdown and JSON state together, and write a session handoff from `project-system/templates/session-handoff.md`. `QUALITY_GATES.md` and acceptance criteria apply — code alone is not completion.
